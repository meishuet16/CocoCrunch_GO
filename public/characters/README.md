# Characters Directory
This directory holds the 5 Duolingo 6-state character sprite sheets:
- `judge.png` (大法官)
- `boy_yellow.png` (夏威夷花衬衫男孩)
- `boy_green.png` (绿帽连帽衫男孩)
- `girl_redhat.png` (红帽女孩)
- `girl_blonde.png` (金发女孩)

They are committed public assets and are served directly from `/characters/`.
